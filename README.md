One line, at most 120 characters: the funniest error message a kitchen toaster would show its owner. The program writes the line to /output/entry.txt, and an AI judge compares entries two at a time on funniness, freshness and tightness.

## Run it

```sh
python3 main.py  # writes the entry to /output/entry.txt
```
